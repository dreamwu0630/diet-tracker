# 我的專屬健康飲食手帳

這是一個專為高壓、時間零碎的雙寶家長設計的飲食追蹤系統。為了改善中度脂肪肝與減重 7~10%，系統主打「最小阻力、不需秤重計算」，利用 LINE 結合 AI 自動運算，無痛記錄日常飲食與身體回饋。

## 一、 系統架構與自動化資料流

這套系統把 LINE 當作輸入框，把複雜的整理工作全部交給雲端：
* **日常紀錄 (LINE Bot)：** 透過 LINE 官方帳號輸入日常飲食文字，作為系統最前線的無感輸入介面[cite: 5]。
* **雲端自動化中樞 (Make)：** 建立 24 小時背景監聽與排程，接收 LINE 傳遞過來的訊息[cite: 5]。
* **大腦處理中心 (Gemini AI)：** 接收文字後進行語意解析，自動萃取並回傳標準化數據，包含：食物標題、熱量、蛋白質、衝擊分析與優化建議[cite: 5]。
* **雲端大冰箱 (Firebase)：** 採用 Google Cloud Firestore 將 AI 運算後的紀錄存放在 `diet_records` 中，支援跨裝置即時同步，讓手機與電腦的數據零時差對齊[cite: 4, 5]。

## 二、 核心功能與介面設計

這是一座託管於 GitHub Pages 的展示廳，支援手機與電腦瀏覽器的響應式排版[cite: 4, 5]：
* **動態時間軸與數據儀表板：** 
  * 以週、日為單位自動分組，動態呈現各餐期（早、午、晚、宵夜）的專屬圖示與營養卡片[cite: 4, 5]。
  * 即時計算並顯示當週與當日的總熱量與總蛋白質結算，並內建水分追蹤進度條[cite: 5]。
* **對抗脂肪肝的體態追蹤：** 內建專屬的體態數據模組，聚焦追蹤體重、體脂率與腰圍，形成強烈的環境制約[cite: 4, 5]。
* **資料防呆與管理機制：** 
  * **Markdown 增量同步：** 支援貼上表格覆蓋更新雲端舊資料，自動過濾雜訊[cite: 4, 5]。
  * **雲端即時刪除：** 網頁上的刪除操作會同步觸發 Firebase API，直接銷毀雲端原始檔案[cite: 4, 5]。
  * **JSON 備份與還原：** 支援一鍵完整備份與還原雲端資料庫[cite: 4, 5]。
